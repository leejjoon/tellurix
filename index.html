tellurix

Differentiable telluric absorption for high-resolution spectra

Every ground-based spectrum is the source multiplied by the transmission of Earth’s atmosphere. tellurix computes that transmission line by line, from the molecules’ laboratory line parameters and the atmosphere’s pressure, temperature and composition at the time of observation. It then fits it to the observed spectrum and divides it out.

It is written in JAX on top of ExoJAX. The whole model, from line opacity to detector pixels, is therefore one compiled, differentiable function: it runs on a GPU and returns exact gradients for fitting. LBLRTM, the standard atmospheric line-by-line code, is its accuracy reference.

Accurate

Given the same atmospheric layers, tellurix matches LBLRTM 12.17 to 0.010% median and 0.039% at the 99th percentile at R = 45,000. It uses AER Line File 3.9, the MT_CKD 4.3 water continuum, pressure shifts and first-order CO₂ line coupling.

Fast and differentiable

Reverse-mode autodiff gives the gradient of the fit objective with respect to every parameter in one pass. With the opacity precomputed, a gradient costs a few milliseconds on one GPU, about 240× faster than the finite differences an LBLRTM-based fit needs.

IGRINS

Per-order fits of A0V standards from Gemini South, DCT and McDonald reach about 1.3σ on a dry night. A night calibration then corrects science targets with only one water scale and one velocity per frame.

FTS atlases

The whole Arcturus infrared atlas (598 page-epochs, 0.91–5.4 µm) and the NSO Kitt Peak solar atlases are corrected. Each spectrum’s instrumental profile is measured from its own interferogram envelope.

How it works

The atmosphere, line opacity and continuum are interchangeable components. Together they give the transmission, which an observation model turns into detector pixels: stellar spectrum, Doppler shifts, line-spread function, pixel integration and a smooth continuum. A bounded fit then adjusts a handful of parameters: one column scale per gas, the velocity, the line-spread-function width and the continuum. The forward-model chapter explains each step from first principles and compares it with LBLRTM’s implementation.

Packages

The repository is a workspace of three packages. The core knows no instrument; instrument packages build on it.

Package Import What it contains
tellurix tellurix Forward model, line opacity, MT_CKD and O₂ continua, fitter, stellar source, site profiles, run records, LBLRTM reference tooling
tellurix-fts tellurix_fts Readers for the Arcturus and NSO solar FTS atlases, interferogram-based instrument profiles, the solar window fit
tellurix-igrins tellurix_igrins IGRINS reduced-spectrum reader, night calibration, lamp-flat blaze, the per-order standard-star fit

Get started

git clone https://github.com/leejjoon/tellurix.git
cd tellurix
uv sync --dev --extra gpu        # Python 3.10; omit --extra gpu for CPU only
uv run tellurix-download-data all  # AER Line File 3.9 and MT_CKD 4.3, SHA-256 checked

See Getting started for a first transmission spectrum in about twenty lines.

Status and citation

tellurix is research software under active development, and a paper describing it is in preparation; its working draft is on this site. To cite a released version of the code and its fitted products, use the Zenodo record 10.5281/zenodo.23121556, which covers all versions.

tellurix is released under the MIT License. The three modules derived from AER’s MT_CKD and LBLRTM continuum code stay under AER’s terms: free for research use, but not for commercial software without AER’s consent.
