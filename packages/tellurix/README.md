# tellurix

A differentiable JAX forward model for terrestrial (telluric) absorption in
high-resolution spectra: ExoJAX line-by-line opacity through a layered
atmosphere, slant-path transmission, an instrument model, and a bounded MAP
fitter. It knows no instrument; readers for particular data are in
`tellurix-fts` and `tellurix-igrins`.

See the repository README for the environment, data downloads and validation.
